Kalkulator Nilai UT

Simulasi estimasi nilai akhir mata kuliah Universitas Terbuka. Bukan alat resmi.

Atur bobot penilaian

Bobot UAS = 100 dikurangi bobot tutorial. Bawaan: TTM/Tuweb 50% dan Tuton 30%, sesuai materi resmi UT. Bobot praktik 30% masih asumsi. Nilai tutorial hanya dihitung jika UAS minimal 30% benar, dan jika UAS lebih tinggi dari hasil gabungan, dipakai nilai UAS.

Buka MyUT (nilai resmi)

Lihat skor tuton dan hasil resmi di MyUT, lalu isi manual di kalkulator ini. Halaman nilai resmi: ut.ac.id/nilaimatakuliah.

Sumber: halaman kalender akademik program studi di ut.ac.id (jalur umum). Tanggal bisa berbeda untuk RPL atau program lain, jadi pastikan dengan kalender resmi UT atau MyUT. Jadwal UAS CBT/THE, pengumuman nilai, dan wisuda belum tercantum.

Petunjuk Penggunaan
  1. Isi nama mata kuliah (boleh dikosongkan) dan jumlah SKS agar IPK simulasi bisa dihitung.
  2. Pilih jenis pembelajaran: TTM / Tuweb / Tutorial Online, atau Berpraktik.
  3. Isi jumlah jawaban benar UAS dan pilih jumlah soal. Kalau jumlah soalnya tidak ada di daftar, pilih Input manual.
  4. Isi skor TTM / Tuton. Untuk mata kuliah berpraktik, isi nilai tugas T1, T2, dan T3.
  5. Pilih tingkat kesulitan mata kuliah (mudah, sedang, atau sulit). Tingkat ini menentukan batas nilai huruf.
  6. Klik Hitung Estimasi Nilai. Hasilnya berupa nilai angka, huruf, dan mutu.
  7. Klik Tambah ke daftar untuk mengumpulkan beberapa mata kuliah dan melihat rata-rata mutunya.

Tugas berpraktik yang tidak dikumpulkan harus dikosongkan, bukan diisi 0. Tugas yang kosong tidak ikut dihitung.

Informasi penting
  • Hasil hanya estimasi untuk memprediksi nilai akhir dengan skema pilihan ganda, dari jumlah benar yang kamu perkirakan sendiri.
  • Nilai resmi hanya ada di MyUT saat pengumuman nilai.
  • Bobot bawaan mengikuti materi resmi UT: TTM/Tuweb 50% dan Tuton 30% terhadap nilai akhir. Nilai tutorial baru dihitung jika UAS minimal 30% benar, dan jika UAS lebih tinggi dari hasil gabungan, dipakai nilai UAS. Bobot berpraktik (30%) masih asumsi, ubah di Atur bobot penilaian bila Katalog UT menyebut angka lain.
  • IPK simulasi dihitung dari mata kuliah di daftar: jumlah (mutu x SKS) dibagi total SKS.
  • Gunakan hasil ini sebagai pertimbangan awal, misalnya untuk memutuskan perlu remidial atau tidak.
Istilah
  • UAS: Ujian Akhir Semester.
  • TTM / Tuweb: Tutorial Tatap Muka / Tutorial Web.
  • Tuton: Tutorial Online, diaktivasi lewat MyUT.
  • Mutu: bobot nilai huruf (A = 4.0 sampai E = 0.0).
Tanya jawab
Apakah aplikasi ini berbayar?

Tidak, gratis.

Apakah hasilnya 100% akurat?

Tidak. Ini alat simulasi. Hasil resmi tetap di MyUT dan bisa berbeda karena faktor lain.

Apakah data saya disimpan?

Tidak. Semua perhitungan hanya di browser perangkatmu. Satu-satunya yang diingat adalah pilihan mode gelap atau terang.

Apakah ini terhubung ke MyUT?

Tidak. Aplikasi ini tidak meminta login dan tidak mengambil data dari MyUT. Isi skor secara manual.

Cara mengganti mode gelap atau terang?

Klik tombol di pojok kanan atas. Secara bawaan, tampilan mengikuti pengaturan perangkatmu.

Aplikasi tidak resmi dan tidak berafiliasi dengan Universitas Terbuka.
