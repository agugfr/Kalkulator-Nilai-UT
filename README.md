# Kalkulator-Nilai-UT
Simulasi estimasi nilai akhir mata kuliah Universitas Terbuka. 
Fitur
Hitung Nilai: input jenis pembelajaran (TTM/Tuweb, Tuton, atau Berpraktik), jawaban benar dan jumlah soal UAS, skor tutorial atau tugas, serta tingkat kesulitan. Hasilnya nilai angka, huruf, dan mutu.
Daftar mata kuliah dan IPK simulasi: ada kolom SKS, dan IPK dihitung dari mutu x SKS.
Kalender Akademik: jadwal Program Sarjana 2026/2027 dan hitung mundur ke UAS tatap muka berikutnya.
Petunjuk: cara pakai, informasi penting, istilah, dan tanya jawab.
Mode gelap: tombol di pojok kanan atas, otomatis mengikuti pengaturan perangkat.
Tombol MyUT: membuka myut.ut.ac.id dan halaman nilai resmi UT.

Rumus yang dipakai

Bobot tutorial: TTM/Tuweb 50% dan Tuton 30%.
Nilai tutorial hanya dihitung jika UAS minimal 30% benar.
Jika UAS lebih tinggi dari hasil gabungan, dipakai nilai UAS.
Bobot berpraktik (30%) masih asumsi, belum ada sumber resminya.
